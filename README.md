# Card Pack Demo

Simple browser-based demo of a card pack system. It runs entirely in the browser and stores data in localStorage.

Features:
- Packs: Starter, Fortified, Standard, Advanced, Premium, Divine
- One currency: coins (dev top-up button included)
- Sample card library with one example per rarity
- Buy and open packs, collection view, persistent local storage

How to run
1. Open index.html in a browser (or visit the GitHub Pages URL once published).
2. Use the "+1000 Coins (dev)" button to add coins and buy packs.

Notes
- This is a demo/proof-of-concept. All logic runs client-side and is not secure for production.
- Replace or expand GAME_DATA in data.js to add cards and tune drop weights.
